# Bakery E-Commerce Web App

A responsive full-stack web application built for a local bakery to manage product displays and customer order inquiries.

## Tech Stack
* **Languages:** Java, HTML, CSS, JavaScript
* **Backend:** Java Servlets, JavaServer Pages (JSP)
* **Database:** PostgreSQL

## Key Features
* Dynamic product catalog loaded from a relational database
* Custom Java Servlet routing for backend request processing
* Structured PostgreSQL schema for managing inventory and orders
* Responsive front-end interface
